# AETHER_ANIMUS 🌌

A high-fidelity, AI-driven interactive website generation engine. Built for the CORTEX agent and standalone deployment.

## Features
- **Vibe Coding**: Generate premium websites via natural language prompts.
- **GSAP Scrollytelling**: Smooth, scroll-triggered animations out of the box.
- **Three.js Interactivity**: Integrated 3D elements (Hero section or background).
- **Glassmorphism UI**: Modern, sleek, dark-mode design system.

## Project Structure
- `animus_engine.py`: Core generation logic.
- `components.py`: GSAP & Three.js integrated UI library.
- `templates/base_styles.css`: The Aether Design System.

## Usage
1. Define your project data in a JSON/Dict format.
2. Run `AnimusEngine().generate_site(data)`.
3. Open `generated_site/index.html` to experience the magic.
